# ניטור מניות S&P 500 — איתותי הזדמנות לרווח מהיר

> ⚠️ **דיסקליימר:** זהו כלי סיגנלים/מחקר אישי בלבד. הוא **אינו** ייעוץ השקעות, אינו
> המלצה לרכישה או מכירה, ואינו מהווה תחליף לשיקול דעת מקצועי. כל החלטת מסחר
> וכל תוצאה כספית הן באחריותכם המלאה בלבד.

ריפו **עצמאי ונפרד** — פרויקט Flask פשוט שרץ כשירות Render יחיד (+ Cron job).

---

## 1. מה המערכת עושה

כל 15 דקות בשעות המסחר של וול סטריט, המערכת סורקת את כל מדד **S&P 500**
ומחשבת לכל מניה "ציון הזדמנות" המבוסס על 4 מרכיבים שקופים לגמרי:

| מרכיב | מה זה בודק | סף כניסה |
|---|---|---|
| **פריצת נפח** | נפח המסחר ב-3 העמודות (candles) האחרונות (15 דק') מול הבייסליין שלפניהן | x2.0 ומעלה — **תנאי חובה** |
| **מומנטום** | שינוי % במחיר בשעה האחרונה (4 עמודות של 15 דק') | +1.5% ומעלה — **תנאי חובה** |
| **פריצת שיא** | האם המחיר הנוכחי גבוה מהשיא ב-5 השעות האחרונות | בונוס לציון |
| **מגמה + RSI** | מחיר מעל ממוצע נע 20 יום (EMA20 יומי), ו-RSI(14) בטווח 45-82 (לא "קנוי יתר על המידה") | בונוס/קנס לציון |

רק מניה שעברה את **שני התנאים החובה** (נפח + מומנטום) ומצטרפת לציון משוקלל
של **70 ומעלה** (מ-100) מייצרת איתות. לכל איתות מחושבים גם **סטופ-לוס**
ו**יעד** גנריים (3% / 6% מנקודת הכניסה, ביחס סיכוי:סיכון של 2:1) — כלי
עזר להערכת סיכון, לא המלצה מדויקת.

איתות נשלח **פעם אחת ביום לכל מניה** (דדופ) — כדי לא להציף בהתראות חזרתיות
על אותו מומנטום.

קוד הציון נמצא ב-`scanner.py`, פונקציה `analyze_ticker()` — כל הסבירים
לשינוי (VOL_SPIKE_MIN, MOMENTUM_MIN_PCT, SIGNAL_THRESHOLD וכו') מוגדרים
כקבועים בראש הקובץ, לכיוונון קל.

## 2. מגבלות שכדאי להכיר (כנות מקצועית)

- **הדאטה אינו זרם אמת (tick-by-tick).** נשלף מ-yfinance (מקור חינמי) — לרוב
  יש דיליי קטן. הסריקה רצה כל 15 דק' בשעות המסחר; זו "בזמן אמת" ברמה
  שאפשר להשיג בלי לשלם על פיד בורסה.
- **yfinance לא רשמי** — הוא "מגרד" נתונים מיאהו פייננס ולא API רשמי נתמך.
  יאהו מדי פעם חוסם/מגביל גישה אוטומטית (כולל מכתובות IP של שירותי cloud
  כמו Render). אם זה קורה, הסריקה נכשלת בעדינות (רושמת שגיאה, שולחת
  התראת שגיאה בטלגרם אם מוגדר, ומנסה שוב בסריקה הבאה) — אבל אם זה
  נמשך, יידרש מקור דאטה חינמי/בתשלום אחר (למשל Finnhub / Twelve Data /
  Alpaca Market Data).
- **האסטרטגיה היא מומנטום/פריצה** — מתאימה לזיהוי תנועה חדה שקורית *עכשיו*.
  היא לא "משקיעה לטווח ארוך" ולא מבטיחה רווח — שוק יכול להפוך כיוון
  בכל רגע אחרי האיתות.
- רשימת החברות במדד מתעדכנת מקובץ קהילתי ב-GitHub (עם עותק גיבוי מקומי
  בקובץ `sp500_fallback.csv`), ומתעדכנת אוטומטית כל 24 שעות.

## 3. הקמת בוט טלגרם — צעד אחר צעד

1. פתחו את טלגרם וחפשו את המשתמש **@BotFather** (עם ה-checkmark הכחול).
2. שלחו לו `/newbot`.
3. הוא ישאל לשם תצוגה לבוט — כתבו למשל `Stock Monitor Daniel`.
4. הוא ישאל לשם משתמש (username) — חייב להסתיים ב-`bot`, למשל `daniel_stock_monitor_bot`.
5. BotFather יחזיר הודעה עם **טוקן** שנראה כך: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   **זה ה-`TELEGRAM_BOT_TOKEN`** — שמרו אותו, הוא סודי.
6. עכשיו צריך את **chat_id** שלכם (לאן הבוט ישלח הודעות):
   - פתחו שיחה עם הבוט שיצרתם (חפשו את ה-username שנתתם לו) ולחצו **Start** /
     שלחו לו כל הודעה (למשל "הי").
   - בדפדפן, גשו לכתובת (החליפו `<TOKEN>` בטוקן שקיבלתם):
     `https://api.telegram.org/bot<TOKEN>/getUpdates`
   - בתשובת ה-JSON תחפשו `"chat":{"id":123456789, ...}` — המספר הזה הוא
     **ה-`TELEGRAM_CHAT_ID`**.
   - אם התשובה ריקה (`"result":[]`) — סימן שלא שלחתם הודעה לבוט קודם; חזרו
     על השלב הקודם ונסו שוב.
7. את שני הערכים (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) מכניסים
   כמשתני סביבה בשירות `stock-monitor` ב-Render (Dashboard → Environment).

## 4. הקמה ב-Render

1. חברו את הריפו ל-Render (אם עדיין לא מחובר) — Render יזהה את `render.yaml`
   בשורש ויציע ליצור את כל השירותים המוגדרים בו, כולל `stock-monitor` ו-
   `stock-monitor-scan`.
2. לאחר היצירה, הגדירו ב-Environment של שירות `stock-monitor`:
   - `DASHBOARD_PASSWORD` — סיסמה לכניסה לדשבורד (בחרו סיסמה חזקה).
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — מסעיף 3 לעיל.
3. עדכנו את `APP_URL` בשני השירותים (`stock-monitor` וה-cron) לכתובת
   האמיתית שרנדר הקצה (`https://<שם-השירות>.onrender.com`).
4. פריסה (Deploy). הדשבורד יהיה בכתובת שקיבלתם, מוגן בסיסמה.
5. לבדיקה ידנית מיידית (בלי לחכות לקרון), אפשר לקרוא (מדפדפן/curl):
   `https://<APP_URL>/api/scan?token=<CRON_TOKEN>&force=1`
   (`force=1` מדלג על בדיקת "שוק פתוח" — שימושי לבדיקה גם מחוץ לשעות המסחר).

## 5. הרצה מקומית (לבדיקות)

```bash
pip install -r requirements.txt
export DASHBOARD_PASSWORD=test123
export CRON_TOKEN=localtest
python server.py   # http://localhost:5001
```

## 6. מבנה הקוד

```
server.py            Flask: login, דשבורד, /api/status, /api/scan
scanner.py            אוניברסת S&P 500 + שליפת דאטה + חישוב ציון האיתות
storage.py            SQLite: היסטוריית סריקות ואיתותים
telegram_notify.py    שליחת התראות טלגרם
cron_scan.py          סקריפט שה-Render Cron מריץ (קורא ל-/api/scan)
sp500_fallback.csv    עותק גיבוי מקומי לרשימת מדד S&P 500
templates/, static/   דשבורד ה-Web
```
